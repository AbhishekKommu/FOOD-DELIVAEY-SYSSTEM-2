# 🍔 Food Delivery System

A modern and user-friendly **Food Delivery System** designed to simplify online food ordering. The application allows users to explore restaurants, browse menus, add food items to a cart, place orders, and view their order history.

## 🚀 Features

* 🔐 User Login & Registration
* 🏪 Restaurant Listing
* 🔎 Search & Filter Restaurants
* 🍕 Restaurant Menu Browsing
* 🛒 Add to Cart & Cart Management
* 💳 Checkout & Order Placement
* 📦 Order History
* 👤 User Profile Management
* 🔄 REST API Integration
* 🗄️ Database Connectivity
* 📱 Responsive & User-Friendly UI
* ✨ Modern Animated Background

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/food-delivery-system.git
```

### 2. Open the Project

```bash
cd food-delivery-system
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

### 4. Activate Virtual Environment — Windows

```bash
venv\Scripts\activate
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the Application

```bash
python app.py
```

### 7. Open in Browser

```text
http://127.0.0.1:5000
```
